------------------

### 1. **Inspect Command**

The `inspect` command takes a Python file as input and outputs its structure as JSON. It uses the Abstract Syntax Tree (AST) module to extract information about imports, functions, classes, arguments, decorators, docstrings, and line numbers.

Here's an example of how you can use the `inspect` command:
```bash

```
This will output a JSON file containing the structure of your Python code.

The `explain` command takes a Python file as input and generates a Markdown walkthrough of its code. It uses the AST module to parse the code, runs code quality analysis, and generates a structured report. Optionally, it can also add an LLM-powered explanation using the Ollama model.

Here's an example of how you can use the `explain` command:
```bash

```
This will generate a Markdown file containing a walkthrough of your Python code and write it to the specified output path.

4. **Report Generation**: The `render` function generates a structured report based on the parsed code, analysis results, and optional LLM explanation.
