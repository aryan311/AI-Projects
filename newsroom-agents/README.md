# NewsRoom Agents

NewsRoom Agents is a Python A2A-style news briefing pipeline. Small typed agents fetch, normalize, summarize, and edit article briefs with source links.

## Why This Project Exists

A2A projects often become vague strings passed between fake agents. This project keeps agent responsibilities explicit and validates every handoff with Pydantic models.

## Hiring Signal

NewsRoom Agents proves:

- agent workflow design
- typed message contracts
- external API/RSS ingestion
- retries and normalization
- source tracking
- pipeline tests
- optional observability

## Core User Story

As a user, I enter a topic and receive a source-linked news briefing generated by multiple agents with visible handoffs.

## Agents

- Research Agent: fetches articles from RSS feeds
- Normalize Agent: converts articles to a common schema
- Summary Agent: summarizes each article
- Editor Agent: creates the final briefing

## MVP Features

- topic input
- RSS feed fetching
- article normalization
- duplicate removal
- article summaries
- final briefing with source links
- run log showing agent handoffs
- Pydantic message schemas

## Stretch Features

- OpenTelemetry spans per agent
- saved fixtures for evaluation
- duplicate story clustering
- agent run timeline endpoint
- source reliability labels

## Architecture

```text
Topic
  -> ResearchAgent
  -> NormalizeAgent
  -> SummaryAgent
  -> EditorAgent
  -> Briefing
```

## Message Contracts

All agents communicate through typed models:

- `Article`
- `ResearchResult`
- `NormalizedArticle`
- `ArticleSummary`
- `Briefing`

## Testing Strategy

- message contract tests
- RSS fixture tests
- pipeline tests
- duplicate removal tests
- source link presence tests

## Steps to run

- python main.py
- open localhost:8000 and enter topic to search
